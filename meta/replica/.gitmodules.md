# `.gitmodules`

Source: `.gitmodules`

This file records Git submodule configuration for the repository. It currently
declares `meta/pdpmake`, pointing at
`https://github.com/reshlet-reshi/pdpmake`.

The submodule lives under `meta/` because it is build-validation tooling, not
part of the source distribution. `meta/pdpmake.sh` builds a scratch copy of
pdpmake under `.make/pdpmake`, and `meta/test-pdpmake.sh` uses that wrapper
for commit-gated Makefile compatibility checks.
