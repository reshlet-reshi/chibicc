# `.gitmodules`

Source: `.gitmodules`

This file records Git submodule configuration for the repository. It currently
declares:

- `meta/pdpmake`, pointing at `https://github.com/reshlet-reshi/pdpmake`
- `meta/stage0-posix`, pointing at
  `https://github.com/reshlet-reshi/stage0-posix.git`

Both submodules live under `meta/` because they are validation or experimental
tooling, not part of the source archive. `meta/pdpmake.sh` builds a scratch
copy of pdpmake under `.make/pdpmake`, and `meta/test-pdpmake.sh` uses that
wrapper for Makefile compatibility checks. `meta/stage0-qemu.sh` uses the
stage0-posix submodule as input for the manual QEMU bootstrap experiment.
