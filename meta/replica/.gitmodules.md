# `.gitmodules`

Source: `.gitmodules`

This file records Git submodule configuration for the repository. It currently
declares:

- `meta/live-bootstrap`, pointing at
  `https://github.com/reshlet-reshi/live-bootstrap`
- `meta/pdpmake`, pointing at `https://github.com/reshlet-reshi/pdpmake`
- `meta/stage0-posix`, pointing at
  `https://github.com/reshlet-reshi/stage0-posix.git`

These submodules live under `meta/` because they are validation or
experimental tooling, not part of the source archive. `meta/pdpmake.sh` builds
a scratch copy of pdpmake under `.make/pdpmake`, and `meta/test-pdpmake.sh`
uses that wrapper for Makefile compatibility checks. `meta/stage0-qemu.sh`
uses the stage0-posix submodule as input for the manual QEMU bootstrap
experiment. `meta/live-bootstrap` is pinned for future incremental bootstrap
integration work.
